# 设置

## 首次使用

**添加曲库**：设置 → 文件夹管理 → 添加文件夹

**选择输出设备**：设置 → 音频 → 输出设备

**在线歌词**：设置 → 歌词 → 启用在线歌词（默认开启）

## 音质优化

**均衡器**：设置 → 音频 → 均衡器。10 段 EQ，预设或自定义。

**WASAPI 独占**：设置 → 音频 → 启用 WASAPI 独占。绕过混音器，降低延迟。

**变调变速**：设置 → 播放 → 音调 / 速度。

## 界面调整

**主题**：自动跟随系统 / 浅色 / 深色

**主题色**：自动取色 / 自定义

**字号**：设置 → 外观 → 字号

**窗口记忆**：关闭窗口时记住位置和大小

## 歌词显示

**字号**：设置 → 歌词 → 字号

**对齐**：居中 / 左对齐

**翻译**：显示翻译行

**罗马音**：显示罗马音行

**桌面歌词**：独立窗口显示歌词

## 播放行为

**淡入淡出**：歌曲开始和结束时的音量渐变时长

**自动播放**：打开应用时自动播放上次歌曲

**关闭行为**：最小化到托盘 / 直接退出
