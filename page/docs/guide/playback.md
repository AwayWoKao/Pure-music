# 播放与音频

## 播放模式

**顺序播放** — 按列表顺序

**单曲循环** — 重复当前歌曲

**随机播放** — 打乱顺序

## 音质设置

### 输出设备

设置 → 音频 → 输出设备。选择声卡或 USB DAC。

### WASAPI 独占

独占模式绕过 Windows 混音器，直接输出到硬件。

启用方式：设置 → 音频 → 启用 WASAPI 独占。

**注意**：独占期间其他应用无法播放声音。

### 10 段均衡器

设置 → 音频 → 均衡器。频段：31 / 62 / 125 / 250 / 500 Hz / 1K / 2K / 4K / 8K / 16K。

预设：流行、摇滚、古典、爵士、人声。

## 变调变速

**变调**：调整音高，不改变速度。范围 -12 到 +12 半音。

**变速**：调整速度，不改变音高。范围 0.5x 到 2.0x。

设置 → 播放 → 音调 / 速度。

## 淡入淡出

**淡入**：歌曲开始时音量从 0 渐变到设定值。

**淡出**：歌曲结束时音量渐变到 0。

设置 → 播放 → 淡入淡出时长。
