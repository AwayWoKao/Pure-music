# 操作指南

## 鼠标手势

**播放页**

- 上下滑动：切换歌曲
- 左右滑动：快进快退
- 双击：播放/暂停
- 双指捏合：缩放封面

**曲库页**

- 双击歌曲：播放
- 右键歌曲：菜单
- 拖动歌曲：添加到歌单

## 快捷键

| 功能 | 快捷键 |
|------|--------|
| 播放/暂停 | `Space` |
| 上一曲 | `Ctrl+Left` |
| 下一曲 | `Ctrl+Right` |
| 音量增加 | `Ctrl+Up` |
| 音量减少 | `Ctrl+Down` |
| 快进 5 秒 | `Right` |
| 快退 5 秒 | `Left` |
| 切换歌词 | `L` |
| 切换播放模式 | `M` |
| 打开搜索 | `Ctrl+F` |

完整快捷键列表见 [GitHub Wiki](https://github.com/qingyueyin/Pure-music/wiki/Keyboard-Shortcuts)。
