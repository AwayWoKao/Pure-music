# 操作指南

快捷键可在「设置 → 播放」里改。全局热键默认关闭，打开后最小化也能用。

## 默认快捷键

| 功能 | 按键 |
|------|------|
| 播放 / 暂停 | `Space` |
| 上一曲 / 下一曲 | `Ctrl + ←` / `Ctrl + →` |
| 应用音量 | `Ctrl + ↑` / `Ctrl + ↓` |
| 随机 | `Ctrl + S` |
| 沉浸 | `F1` |
| 桌面歌词 | `F2` |
| 睡眠定时 | `F8` |
| 全屏 | `F11` |
| 关闭 / 返回 | `Esc` |

全局热键可绑：播放 / 暂停、上一曲、下一曲、随机、桌面歌词。

在搜索框打字或弹出对话框时，播放快捷键会暂时关掉。

## 鼠标

- **侧键** — 返回上一页；沉浸模式下退出沉浸
- **进度条拖动** — 定位
- **点击歌词行** — 跳到这句
- **长按 / 拖选** — 多选
- **右键** — 菜单（含下一首播放）
- **顶栏搜索** — 搜歌曲 / 艺术家 / 专辑，支持拼音首字母
