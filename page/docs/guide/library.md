# 音乐库

## 浏览方式

**音乐** — 全部歌曲列表

**艺术家 / 专辑** — 按元数据分组

**文件夹** — 按目录结构浏览

**歌单** — 自建列表

## 曲库管理

### 添加文件夹

设置 → 文件夹管理 → 添加文件夹。选择音乐所在的上层目录，子文件夹会递归扫描。

### 刷新曲库

修改了本地音乐文件后，点击「重新构建曲库」使改动生效。

### 移除文件夹

文件夹管理 → 移除。移除后该目录下的歌曲会从曲库中消失，但本地文件不会被删除。

## 元数据编辑

右键歌曲 → 编辑信息。修改后会写回音频文件的内嵌标签。

**支持的字段**：标题、艺术家、专辑、专辑艺术家、年份、音轨号、封面。

**批量编辑**：选中多首歌曲右键，可统一修改艺术家、专辑等字段。
