# 歌词

## 支持格式

**逐字高亮**：YRC / QRC / KRC / TTML

**逐行高亮**：LRC

## 歌词来源

### 内嵌歌词

音频文件内嵌的 LRC 格式歌词，优先级最高。

### 外部歌词文件

与音频同名的 `.lrc` / `.yrc` / `.qrc` / `.krc` / `.ttml` 文件。

### 在线歌词

自动从第三方平台搜索。设置 → 歌词 → 启用在线歌词。

## 歌词编辑

播放页右键歌词区 → 编辑歌词。保存后会写入同名 `.lrc` 文件。

## 歌词样式

**字号**：设置 → 歌词 → 字号

**对齐**：设置 → 歌词 → 对齐方式（居中 / 左对齐）

**翻译**：启用后显示翻译行（需歌词文件包含翻译）

**罗马音**：启用后显示罗马音行（需歌词文件包含罗马音）
