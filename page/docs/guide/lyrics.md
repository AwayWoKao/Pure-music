# 歌词

YRC / QRC / KRC / TTML / LRC，逐字或逐行。

## 来源

**外置 / 内嵌**（默认）— 同名 `.lrc` / `.yrc` / `.qrc` / `.krc` / `.ttml`，或音频里的内嵌歌词。

**在线** — 设置 → 歌词 → 首选来源，换成「在线」。可选 QQ / 网易 / 酷狗 / AMLL。

歌词文件与音频同名、放在同一目录。

## 显示

播放页可切换对齐，点击歌词行跳转进度。

**翻译 / 罗马音** — 歌词里带了才会显示；播放页和设置里可单独开关。

**逐字动效** — 设置 → 歌词 → 显示效果：辉光缩放、上抬、行动效。

## 写入

在线搜到的词可写入音频标签或导出 LRC。设置 → 歌词 → 歌词写入。
