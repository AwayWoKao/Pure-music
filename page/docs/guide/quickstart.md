# 快速上手

导入文件夹，等扫描结束，点一首歌即可。

没走欢迎页？之后到「文件夹」→「文件夹管理」添加目录。

## 播放页

- 竖屏 / 横屏自动适配；`F1` 沉浸，`F11` 全屏
- 可在主区、歌词、播放列表之间切换
- 封面会取色，界面和背景跟着变
- 更多见 [播放与音频](/guide/playback)、[歌词](/guide/lyrics)、[操作指南](/guide/interactions)

::: tip 第一次没有歌词？
默认只读外置或内嵌歌词。要联网搜索，到「设置」→「歌词」把首选来源换成「在线」。
:::

## 以后加歌

- 新文件放进已添加的目录后，到「文件夹」点「刷新」
- 增减扫描目录：「文件夹」→「文件夹管理」
- 从曲库移除文件夹只取消索引，不删磁盘上的文件
