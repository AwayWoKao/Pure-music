# 快速上手

从导入曲库到开始播放，大约几分钟。

第一次没走欢迎页？之后进入「文件夹」→「文件夹管理」添加目录，再重新构建曲库。

## 播放页基础

- 竖屏 / 横屏会自动适配；`F1` 进入沉浸模式，`F11` 最大化或还原窗口
- 可切换「仅主区 / 带歌词 / 带播放列表」
- 封面会取色，界面主题和背景会跟着变
- 更多见 [播放与音频](/guide/playback)、[歌词](/guide/lyrics)、[操作指南](/guide/interactions)

::: tip 第一次播放没有歌词？
默认只读取外置或内嵌歌词。需要联网搜索时，到「设置」→「歌词」把首选来源切换为「在线」。
:::

## 以后新增音乐

- 新文件放进已添加的目录后，进入「文件夹」并点击「刷新」
- 要增减扫描目录，进入「文件夹」→「文件夹管理」
- 从曲库移除文件夹只会取消索引，不会删除磁盘上的音乐
